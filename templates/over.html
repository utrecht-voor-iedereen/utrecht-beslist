Wat is Utrecht Beslist?

Utrecht Beslist is een onafhankelijk, open-source burgerinitiatief dat documenten en besluiten van de Utrechtse gemeenteraad automatisch samenvat in begrijpelijke taal (B1-niveau Neerlandés en Engels).

Hoe werkt de pipeline?

  1. Data ophalen: Dagelijks worden nieuwe documenten (raadsvoorstellen, besluiten, moties) opgehaald via de openbare API van Open Raadsinformatie.
  2. Filteren: Trivialiteiten zoals presentielijsten en blanco sjablonen worden automatisch gefilterd.
  3. AI-samenvatting: Documenten worden samengevat via een keten van AI-modellen (Groq, Gemini, OpenRouter). Indien AI onbeschikbaar is, treedt de degradatiemodus in werking en wordt het originele document direct gelinkt.
  4. Transparantie: Elk artikel bevat ALTIJD een rechtstreekse link naar het officiële originele PDF-document van de gemeente Utrecht.

Open Source & Privacy

Dit project is 100% open source gelicentieerd onder EUPL-1.2. Er worden geen cookies, tracking scripts of persoonlijke gegevens verzameld.

What is Utrecht Beslist?

Utrecht Beslist is an independent, open-source civic project that automatically summarizes Utrecht city council documents and decisions into plain language (B1 Dutch and English).

How does the pipeline work?

  1. Fetch Data: New documents (council proposals, decisions, motions) are queried daily via the public Open Raadsinformatie API.
  2. Filtering: Routine administrative items such as attendance logs are automatically filtered out.
  3. AI Summarization: Documents are summarized using a resilient chain of LLMs (Groq, Gemini, OpenRouter). If AI services are offline, degraded fallback mode links the original text.
  4. Transparency: Every summary ALWAYS contains a direct link to the official original PDF document published by the Municipality of Utrecht.

Open Source & Privacy

This project is 100% open source under the EUPL-1.2 license. It uses zero tracking cookies, third-party analytics, or data collection.
