Wat is Utrecht Beslist?

Utrecht Beslist is een onafhankelijk, open-source burgerinitiatief dat documenten en besluiten van de Utrechtse gemeenteraad automatisch verzamelt en samenvat in begrijpelijke taal (B1-niveau).

💡 100% Open Data & Transparantie: Alle gegevens zijn afkomstig van openbare overheidsbronnen. Elke samenvatting bevat een directe verwijzing naar het originele raadsdocument van de Gemeente Utrecht.

🌐 Officiële Bronnen & Partners

Utrecht Beslist maakt rechtstreeks gebruik van de open API's en portalen van de overheid:

  • Open Raadsinformatie (ORI): openraadsinformatie.nl — Het landelijke platform voor open gemeentelijke raadsstukken.
  • Gemeente Utrecht Raadsinformatie: utrecht.bestuurlijkeinformatie.nl — Het officiële raadsinformatiesysteem van de Gemeente Utrecht.
  • Officiële Website Utrecht: utrecht.nl — Portaal van de gemeente Utrecht.

🔄 Hoe werkt de automatische gegevensverzameling?

1. Dagelijkse Ophaal (06:00 UTC)

Via geautomatiseerde GitHub Actions scripts wordt dagelijks de nieuwste raadsinformatie van Utrecht opgevraagd via de ElasticSearch API van Open Raadsinformatie.

2. Automatische Filtering

Niet-relevante administratieve stukken (zoals presentielijsten) worden automatisch gefilterd om alleen inhoudelijke raadsvoorstellen te tonen.

3. AI-Vertaling B1

Taalmodellen (Groq / Llama 3) vertalen het ambtelijke jargon naar begrijpelijke B1-taal, zonder de juridische strekking te veranderen.

4. Statische Publicatie

De website wordt direct opgebouwd als statische HTML-pagina's met een open JSON API (latest.json) zonder cookies of tracking.

Open Source & Licentie

Code en algoritmen zijn 100% open source gelicentieerd onder EUPL-1.2. Bekijk de broncode op GitHub.

What is Utrecht Beslist?

Utrecht Beslist is an independent, open-source civic project that automatically collects and summarizes Utrecht city council documents into plain language (B1 Dutch and English).

💡 100% Open Data & Transparency: All data is sourced from public government APIs. Every summary includes a direct link to the original council document from the Municipality of Utrecht.

🌐 Official Sources & Partners

Utrecht Beslist interfaces directly with official government open data portals:

  • Open Raadsinformatie (ORI): openraadsinformatie.nl — National platform for municipal open council documents.
  • Municipality of Utrecht Council Information: utrecht.bestuurlijkeinformatie.nl — Official council portal of Utrecht.
  • Official Utrecht Portal: utrecht.nl — Municipality of Utrecht website.

🔄 How does the automated pipeline work?

1. Daily Fetch (06:00 UTC)

Automated GitHub Actions workflows query the Open Raadsinformatie ElasticSearch API daily for new Utrecht council documents.

2. Automatic Filtering

Administrative routine files (such as attendance lists) are filtered out automatically to retain only substantive council proposals.

3. AI B1 Translation

Open-weights LLMs (Groq / Llama 3) translate administrative jargon into accessible B1 plain language without altering legal meaning.

4. Static Publishing

The site compiles into 100% static HTML pages with a public open JSON API (latest.json), requiring zero cookies or tracking.

Open Source & License

Code and algorithms are 100% open source licensed under EUPL-1.2. Inspect the source code on GitHub.
